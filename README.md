Following the early success of its Python-based ordering tool, RushMore Pizzeria has expanded to multiple locations with a larger customer base and a more complex menu. However, the original JSON file system has become a major bottleneck—slow, difficult to query, vulnerable to data corruption, and unable to support multiple cashiers simultaneously. Management has rehired you as a Data Engineer and Database Administrator to design a scalable, cloud-based Relational Database Management System (RDBMS). Before migrating real customer data, you must build a proof-of-concept and populate it with over 10,000 rows of realistic, high-quality fake data to test performance, validate data types, and demonstrate analytics capabilities.

The objective is to design, deploy, and populate a production-ready PostgreSQL database in the cloud. I will model RushMore Pizzeria’s operations by creating a normalized, scalable relational schema, then deploy and configure a Database as a Service (DBaaS) on Azure or Google Cloud Platform. Using Python, i will connect to the remote database, generate realistic synthetic data with Faker, and insert it in the correct relational order. The project evaluates your skills in data modeling, cloud deployment, and database programming. Optionally, you may connect an analytics tool to the database to generate insights and answer key business questions.
